# \# CodExam

# 

# CodExam, kullanıcıların seçtikleri programlama dilinde kod yazıp çalıştırabildiği, quiz/sınav oluşturabildiği ve katılımcıların hesap oluşturmadan sınava katılabildiği Docker tabanlı online coding sınav platformudur.

# 

# \## Ekip

# 

# \- Kişi 1: Frontend ve UX

# \- Kişi 2: Backend, Veritabanı ve Quiz Motoru

# \- Kişi 3: Runner, Docker, Nginx ve Sistem

# 

# \## Teknoloji Stack

# 

# \### Frontend

# \- React

# \- TypeScript

# \- Vite

# \- TailwindCSS

# \- Monaco Editor

# 

# \### Backend

# \- ASP.NET Core Web API

# \- Entity Framework Core

# \- PostgreSQL

# \- Redis

# \- SignalR

# \- Hangfire

# 

# \### Altyapı

# \- Docker

# \- Docker Compose

# \- Nginx

# \- Runner Container'lar

# \## Branch Modeli

# 

# \- `main`: Stabil ve teslim edilebilir sürüm
